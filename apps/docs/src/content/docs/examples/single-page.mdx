---
title: One page at a time
description: A book that stays one page wide on any screen, turned from its edges like any other, so the page itself is free for reading.
---

import CoreExample from "../../../components/CoreExample.astro";

Some books shouldn't open into a spread - a phone-sized reader, say, where one page is the whole point. This one stays single however wide the container gets. Turning it works the way it does everywhere else: the outer edge turns forward, the edge by the spine turns back, and the middle of the page is left alone, so selecting text and following links there just work. On a mouse, hovering an edge furls it so you can see where to grab.
