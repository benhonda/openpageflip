Agents know {upstream.name} and {upstream.reactPackage}, and this library is neither, so from memory they write against an API that isn't there. Copy whichever block below fits and you're done.

## Paste this before your request

<Code
  lang="text"
  title="prompt"
  code={`Read ${absoluteUrl(llmsTxt.guides.path)} before writing any code that uses OpenPageFlip. Follow those docs rather than what you know about ${upstream.name} or ${upstream.package}; the API is different.`}
/>

## Or put it in your instructions file

`CLAUDE.md`, `AGENTS.md`, `.github/copilot-instructions.md`, a Cursor rule - whichever file your agent reads at the start of a session. Then you don't have to say it again.

<Code
  lang="md"
  title="AGENTS.md"
  code={`## OpenPageFlip

Page-flip effect for HTML content: \`${corePkg.name}\` (plain JavaScript) and \`${reactPkg.name}\` (React ${reactMajor}).
It is not ${upstream.name} or ${upstream.package}: the API is different, so read the docs before writing code.

- Guides and examples: ${absoluteUrl(llmsTxt.guides.path)}
- Everything, API reference included: ${absoluteUrl(llmsTxt.full)}
`}
/>

## Or give it an address

For tools with a docs-URL setting (Cursor's, for one), this is the one to paste:

<Code lang="text" title="llms.txt" code={absoluteUrl(llmsTxt.index)} />

Every page here is also served as Markdown, generated from the same source at every build. That index links to the <a href={llmsTxt.guides.path}>guides</a> ({llmsTxt.guides.set.description}) and to <a href={llmsTxt.full}>everything</a>, API reference included. Tools that index a whole site can take <a href={siteUrl}><code>{siteUrl}</code></a> and will find the same pages.
