Docs site at https://benhonda.github.io/openpageflip/ with live demos and a generated API reference. READMEs now point there and embed their quick start from the site's own examples, which run in the test suite. Types the public API already referred to are exported so the reference (and your editor) can name them: `ShadowData`, `FlipFrame`, `Emitter`, `Listener`, `LayoutOptions`, `LayoutResult`, `ResolvedOptions` from core and `FlipBookEventProps` from react.
