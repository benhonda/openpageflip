# Security

`@openpageflip/core` and `@openpageflip/react` are published to npm from this repo's `main` branch with npm provenance, so a package version on the registry traces back to a commit and a workflow run here.

If you find a vulnerability, please don't open a public issue. Use GitHub's private reporting on this repo (Security → Report a vulnerability). I'll reply as soon as I've read it, and I'd rather hear about something that turns out to be nothing than not hear at all.

Only the latest published version gets fixes.
